# importer/
Ingests other systems' run artifacts, at rest, into chrono-flight's record form (see `recording.py`). First target: quilt-engine run directories — `seam_log.jsonl` + `sender_book.jsonl` + `receiver_book.jsonl` — one event per source line, kills and open excursions as explicit gap markers. `audit.py` recomputes crossing agreement from the two books alone; `timeline.py` renders the ordered view. The replay limit (judgments shown as recorded, not re-derived) is carried in the module docstring and every timeline output. See ../../ARCHITECTURE.md §1 and ../../BRIDGE-REPORT.md.
