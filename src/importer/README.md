# importer/
Ingests other systems' run artifacts, at rest, into chrono-flight's record form (see `recording.py`). First target: quilt-engine run directories — `seam_log.jsonl` + `sender_book.jsonl` + `receiver_book.jsonl` — one event per source line, kills and open excursions as explicit gap markers. v0.3 runs (engine a54bb51, DESIGN-V03) import with their record kinds intact: revision records (the ex-ante half of the ledger), version citations on every booking, skew markings (superseded citations, citation refusals); fields the tensor form cannot hold are named in the header, never dropped. `audit.py` recomputes crossing agreement from the two books alone — agreement includes the cited version; a superseded citation is agreed with the skew reported; skewed bookings are a category of their own; `version_fold` folds each book's revision records (§4.1 set operation). `timeline.py` renders the ordered view, revision crossings and adoption points included. The replay limit (judgments shown as recorded, not re-derived) is carried in the module docstring and every timeline output. See ../../ARCHITECTURE.md §1, ../../BRIDGE-REPORT.md, ../../BRIDGE-V03-REPORT.md.
